      Hub log

        On the laptop

        MediaPipe finds the face in each video frame and measures 12 features, such as eyebrow height and mouth width. Only those 12 numbers are sent to the hub. The video stays on the laptop.

        On the hub

        The ESP32 stores calibration as running totals per user and gesture. It classifies each incoming frame against those totals in 0.6 ms on average (measured on the board, including the reply).

        Between hubs

        Hubs exchange calibration over ESP-NOW, a direct radio link between ESP32 boards. No router, internet, or server is involved.

        Shared calibration

        A new user starts with everyone else's calibration as a baseline, then adds their own.

        Disconnected hubs

        Hubs keep working when out of range. When they reconnect, their calibration merges to exactly the same result on every hub, regardless of the order updates arrive.

        Deleting data

        Deleting a user creates a deletion record that spreads to every hub. A hub that was offline during the deletion still removes the data when it reconnects, so deleted data never comes back.
